# 実装計画書作成のメタ計画

## 目的
コードレビューで特定されたP0〜P3の課題を、低性能LLMでも実装可能な粒度（1〜24ステップ）に分解した実装計画書を4つ作成する。

## 成果物
1. `P0_CRITICAL_IMPLEMENTATION_PLAN.md` - Critical課題（即対応必須）
2. `P1_HIGH_IMPLEMENTATION_PLAN.md` - High課題（早急対応）
3. `P2_MEDIUM_IMPLEMENTATION_PLAN.md` - Medium課題（計画的対応）
4. `P3_LOW_IMPLEMENTATION_PLAN.md` - Low課題（コード品質改善）

## 各計画書の共通フォーマット
```
# P{X} 実装計画書

## 概要
- 対象課題数: N件
- 総ステップ数: 24ステップ
- 推定工数: X時間

## 前提条件
- Python 3.10+
- 依存パッケージ: 既存requirements.txt準拠
- テスト実行: `pytest tests/ -v`

## ステップ一覧
### Step 1: [具体的なアクション]
- **対象ファイル**: `path/to/file.py`
- **変更内容**: 具体的に何を変えるか
- **確認方法**: どう動作確認するか
- **所要時間目安**: XX分

...

### Step 24: [最終確認・テスト]
- **対象ファイル**: 複数
- **変更内容**: 全体の回帰テスト実行
- **確認方法**: `pytest tests/ -v` 全パス
- **所要時間目安**: 30分

## 依存関係マトリクス
| Step | 依存先 | 備考 |
|------|--------|------|
| 3    | 1, 2   | Step 1,2完了後に実施 |
| ...  | ...    | ... |

## 完了定義
- [ ] 全ステップ実装完了
- [ ] 既存テスト全パス (`pytest tests/ -v`)
- [ ] 新規テスト追加（該当する場合）
- [ ] リンター/型チェック通過 (`ruff check .`, `mypy .`)
- [ ] 手動動作確認完了
```

## 作成順序
1. P0計画書作成（最優先・最小ステップで完結）
2. P1計画書作成
3. P2計画書作成
4. P3計画書作成
5. 全計画書の整合性チェック

## 低性能LLM向け工夫
- 各ステップを「単一ファイル・単一関数・単一変更」に限定
- コピペで動くコード断片を各ステップに記載
- エラーメッセージの想定と対処を明記
- 確認コマンドを正確に記載
