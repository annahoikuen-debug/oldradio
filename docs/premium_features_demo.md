# プレミアム機能デモ・テストシナリオ

このドキュメントは、レトロラジオ・タイムマシンのプレミアム機能をテストするためのシナリオを提供します。

## 前提条件

- アプリがローカルで実行されていること
- テスト用のアカウントがあること（または新規登録できること）

## テストシナリオ

### 1. プレミアムプランへのアップグレード

1. サイドバーの「プレミアムにアップグレードしてエクスポート機能を解放」ボタンをクリック
2. または、サイドバーの「プレミアムにアップグレード」ボタンをクリック
3. 決済ページに遷移することを確認（実際の決済は行わなくても構いません）
4. アップグレード後、サイドバーのプラン表示が「PREMIUM」に変更されることを確認

### 2. プロプランへのアップグレード

1. プレミアムプランにアップグレード後、サイドバーの「プロプランにアップグレードでさらにパワーアップ！」セクションが表示されることを確認
2. 「プロプランにアップグレード」ボタンをクリック
3. 決済ページに遷移することを確認
4. アップグレード後、サイドバーのプラン表示が「PRO」に変更されることを確認

### 3. 高品質音声機能

#### フリープラン
1. フリープランでラジオを生成
2. 生成された音声が標準品質であることを確認（gTTSの標準設定）

#### プレミアムプラン
1. プレミアムプランでラジオを生成
2. 生成された音声が高品質であることを確認（gTTSの高品質設定：lang="ja", tld="co.jp", slow=False）

#### プロプラン
1. プロプランでラジオを生成
2. ELEVENLABS_API_KEYが設定されている場合、ElevenLabs APIを使用した高品質音声が生成されることを確認
3. APIキーがない場合は、プレミアムプランと同じ高品質音声が生成されることを確認

### 4. 履歴エクスポート機能（プレミアムプラン以上）

1. プレミアムプランまたはプロプランにアップグレード
2. 数件のラジオを生成して履歴を蓄積
3. サイドバーの「📥 エクスポート」ボタンをクリック
4. スピンナーが表示され、その後CSVダウンロードボタンが表示されることを確認
5. CSVダウンロードボタンをクリックしてファイルをダウンロード
6. ダウンロードしたCSVファイルに、生成した履歴が正しく含まれていることを確認

### 5. お気に入り機能（プレミアムプラン以上）

1. プレミアムプランまたはプロプランにアップグレード
2. ラジオを生成して履歴を作成
3. 履歴項目の「♥️ お気に入り」ボタンをクリック
4. 「お気に入りに追加しました」というメッセージが表示されることを確認
5. サイドバーの「⭐ お気に入り」セクションに、お気に入りに追加した項目が表示されることを確認
6. お気に入り項目の「再生」ボタンをクリックして、該当のラジオを再生できることを確認
7. お気に入り項目の「♡️ 解除」ボタンをクリックして、お気に入りから削除できることを確認
8. 「お気に入りから解除しました」というメッセージが表示されることを確認

### 6. APIアクセス機能（プロプラン専用）

1. プロプランにアップグレード
2. APIエンドポイント `/api/v1/generate` に対して、プロプランユーザーのトークンを使用してリクエストを送信
3. 202 Accepted レスポンスが返されることを確認
4. フリープランまたはプレミアムプランのユーザーのトークンを使用してリクエストを送信すると、403 Forbidden エラーが返されることを確認

### 7. バッチ生成機能（プロプラン専用）

1. プロプランにアップグレード
2. サイドバーのバッチ生成セクションが表示されることを確認
3. 開始年、終了年、月、日を指定して「バッチ生成を開始」ボタンをクリック
4. スピンナーが表示され、バッチ生成が進行していることを確認
5. バッチ生成が完了したら、結果が表示されることを確認
6. 結果には、指定された年の範囲の各年について、成功または失敗の情報が含まれていることを確認

## 期待結果

- プレミアムプラン以上でエクスポート・お気に入り機能が利用可能
- プロプランでAPIアクセス・バッチ生成機能が利用可能
- フリープランではこれらの機能が制限されていること
- アップグレード・ダウングレード時の機能反映が正常
- すべてのプレミアム機能に適切なエラーハンドリングあり

## トラブルシューティング

- 機能が利用できない場合は、ページをリロードして再試行してください
- アップグレードが反映されない場合は、サインアウトして再サインインしてください
- エラーが発生した場合は、コンソールログを確認してください
